CCNA IP Configuration, Static Routing, DHCP & WAN Network

Cisco Packet Tracer project covering IP addressing, subnetting, static routing, DHCP, DHCP Relay, and Serial WAN connections.

1.IP Configuration & Subnetting
Configured IP addresses, subnet masks, and default gateways for routers and end devices, and divided the network into different subnets.

2.Static Routing
Configured static routes on the routers to define paths to remote networks and allow communication between different LANs.

3.DHCP
Configured a centralized DHCP server to automatically provide IP addresses, subnet masks, and default gateways to client devices.

4.DHCP Relay
Configured `ip helper-address` on remote router interfaces to forward DHCP requests to the centralized DHCP server.

5.Serial WAN
Configured serial connections between routers to create WAN links and connect the different LAN networks.
